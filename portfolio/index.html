THE ROBOT

A little arm,
a complete pipeline.

Luma is an original robot described with URDF primitives. A yawing base supports a shoulder, elbow, and rolling wrist. Two opposing prismatic joints open and close the gripper. Fixed links add the base ring, camera shell, and face.

The choreography is a table of named joint-space targets. A proportional servo moves the joints toward each target. The finite state machine observes the actual joint states and advances when every named joint arrives within its tolerance.

IMPLEMENTATION

Small pieces,
shared contracts.

The runtime reuses the earlier projects’ TCP rosbridge middleware. The parameter server, state publishers, joint servo, and finite state machine communicate through services and topics. The viewer is a separate client. Black-box tests exercise description rejection and rollback, transform accuracy, joint state replacement, world poses, and topic behavior.

All graphics run locally with browser canvas and no external libraries. Boxes, cylinders, and spheres use the first URDF visual on each link. A perspective camera stays separate from the z-up robot coordinate system. The portable recording keeps the choreography viewable without a running Python process.
