## Formula key for math failures

Use **Q** for an xyzw quaternion and **s** for a scalar joint position. Normalize rotation quaternions before rotation/matrix conversion.

- **F1 - Hamilton product**, `T:quaternion_multiply`: write `A=(a,aw)`, `B=(b,bw)`, where a/b are xyz vectors. `A*B = (aw*b + bw*a + a cross b, aw*bw - a dot b)`, then normalize. Rightmost rotation acts first.
- **F2 - Axis rotation**, `T:quaternion_from_axis_angle`: `u = axis / norm(axis)`; `Q = (u.x*sin(s/2), u.y*sin(s/2), u.z*sin(s/2), cos(s/2))`. The prismatic branch does not use this normalization.
- **F3 - Vector rotation**, `T:rotate_vector`: for unit Q, `c = 2*(Q.xyz cross v)`; `rotate(Q,v) = v + Q.w*c + Q.xyz cross c`. Source scales v down before the cross products and restores its scale afterward; handle zero v before division.
- **F4 - Composition**, `T:compose_transforms`: `(tA,QA)*(tB,QB) = (tA + rotate(QA,tB), QA*QB)`. Apply this for every tree edge, with an independent parent pose for each branch.
- **F5 - Matrix**, `T:matrix_column_major`: for unit `(x,y,z,w)`, rotation rows are `[1-2(y*y+z*z), 2(x*y-w*z), 2(x*z+w*y)]`; `[2(x*y+w*z), 1-2(x*x+z*z), 2(y*z-w*x)]`; `[2(x*z-w*y), 2(y*z+w*x), 1-2(x*x+y*y)]`. Homogeneous M is `[R,t;0,0,0,1]`; flatten columns, not rows.
- **F6 - Joint transform**, `D:Joint.joint_transform`: fixed `T_origin`; revolute/continuous `T_origin * [R_axis(s),0;0,1]`; prismatic `T_origin * [I,s*axis;0,1]`. Origin is `[Rz(yaw)*Ry(pitch)*Rx(roll), written_xyz;0,1]`. Never pre-rotate written_xyz or mix a visual origin into this product.
